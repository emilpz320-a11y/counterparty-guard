Counterparty GuardConcordium Trusted Agents · CIS-8004 · x402

“Active” is not “trusted”.

Before an AI agent pays another agent, Counterparty Guard checks the payee on the Concordium CIS-8004 Agent Registry. It verifies the agent is Active, that its Agent Card still matches the on-chain SHA-256 anchor, that a valid Concordium Badge proves an identity-verified owner is accountable, that the x402 payTo is the wallet the agent declared, and that the payment fits per-agent and daily budgets. How the guard decides

  1. Registered & Active: check_badge on the CIS-8004 contract (testnet <12802,0>).
  2. Card integrity: the Agent Card at agent_uri must hash to the on-chain metadata_hash.
  3. Accountable owner: a valid Concordium Badge, which is backed by Concordium's protocol-level identity.
  4. Payment routing: the x402 payTo must equal get_agent_wallet.
  5. Budgets: per-payment, per-counterparty per day and global per day caps in CCD.
  6. History: new agents, past revocations and NFT transfers go to REVIEW.
